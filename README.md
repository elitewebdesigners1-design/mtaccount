ContactBuild a modern, high-conversion full-stack web application for "20 Meter Pharmacy", a premium healthcare and beauty pharmacy located in Summit, Addis Ababa, Ethiopia. The application must be highly responsive, optimized heavily for mobile web users, clean, and use a professional tech stack (React, Tailwind CSS, Lucide Icons, and Supabase for backend integration).



### 1. Design System & Branding

- **Color Palette:** Clean, trustworthy healthcare aesthetic. 

  - Primary: Deep Emerald Green (represents health, trust, and premium service)

  - Secondary: Soft Mint/Teal accents

  - Neutrals: Slate grays for text, crisp white and light gray for backgrounds

- **Typography:** Professional sans-serif (e.g., Inter).

- **Layout:** High scannability, generous whitespace, card-based components with subtle shadows.



### 2. Component Architecture & Features



#### A. Navigation Bar (Sticky)

- Brand name: "20 Meter Pharmacy" with a modern healthcare/leaf icon.

- Desktop Nav: Home, Upload Prescription, Services, Book Consultation, Contact.

- Mobile Nav: Hamburger menu that expands smoothly.

- Persistent Mobile CTA: A prominent, fixed "Call Now" phone icon button tracking to `tel:0911757471`.



#### B. Hero Section

- **Headline:** "Your Health Shouldn't Wait. Check Medicine Availability Instantly."

- **Subheadline:** "Summit’s trusted pharmacy for authentic medications, premium cosmetics, and expert clinical guidance. Open daily from 8:00 AM to 10:00 PM."

- **Primary CTAs (Side-by-Side Grid):**

  1. Button 1 (Primary Style): "Upload Prescription" (Smooth scrolls to the upload form).

  2. Button 2 (Secondary Style with Telegram Icon): "Ask on Telegram" (Launches a placeholder link to a Telegram handle).



#### C. Core Value Proposition (3-Column Grid)

Display cards showcasing why customers choose this shop:

- Card 1: "100% Authentic Medicines" (Icon: ShieldCheck) - Sourced from certified distributors.

- Card 2: "Premium Skincare & Cosmetics" (Icon: Sparkles) - Wide selection of global and local beauty brands.

- Card 3: "Expert Consultations" (Icon: UserCheck) - Dedicated specialists always on hand to assist you.



#### D. Interactive "Prescription Pre-Check" Form (High Leverage Asset)

A clean, secure card interface designed to capture high-intent leads.

- **Form Fields:**

  - Full Name (Text input)

  - Phone Number (Text input, placeholder formatted for Ethiopia: e.g., 0912345678)

  - Additional Notes / Specific Request (Textarea)

  - File Upload Zone: A stylized drag-and-drop component supporting image uploads (PNG, JPG) or PDFs of prescriptions.

- **State Management & Interactivity:** - On submit, connect this form to a Supabase backend table named `prescriptions` to save the metadata.

  - Display a beautiful, animated Success Modal overlay once submitted: "Prescription Received! Our pharmacy team in Summit is checking our inventory right now. We will call or text you within 15 minutes to confirm availability and set aside your items."



#### E. "Skincare & Beauty" Consultation Scheduler

A secondary form lower down the page to book dedicated specialist time.

- **Form Fields:** Name, Phone Number, Date Picker, and Time Slot Dropdown (Options: Morning, Afternoon, Evening).

- Save submissions to a Supabase table named `consultations` and display a clean inline success toast message.



#### F. Contact, Hours & Location Footer

- Grid layout split into three distinct zones:

  1. **Operating Hours:** "Open 7 Days a Week: 8:00 AM – 10:00 PM" (Use an Icon: Clock).

  2. **Direct Lines:** Clickable links for Phone (`tel:0911757471`) and Telegram.

  3. **Location:** Text detailing "Summit Area, Addis Ababa, Ethiopia" with an embedded map placeholder component (a beautifully styled container mimicking an interactive Google Map layout).



### 3. Technical Constraints & UI Experience

- Ensure perfect responsive breakpoints (`sm`, `md`, `lg`) prioritizing the mobile layout, as most traffic will come from smartphones.

- Include subtle micro-interactions: Hover states on buttons, smooth scrolling for all anchor links, and loading spinners on the forms during submission.
